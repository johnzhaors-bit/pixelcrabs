# Security Policy

## Reporting a vulnerability

Please do not disclose a suspected vulnerability in a public issue.

Use GitHub's private vulnerability reporting feature for this repository when available. If it is unavailable, contact the maintainer through the private contact method listed on the official PixelCrabs website.

Include:

- the affected commit and component;
- reproduction steps or a minimal proof of concept;
- the expected impact;
- any known mitigation.

Do not include real API keys, access tokens, certificates, cookies, customer data or private source code. Use synthetic fixtures and revoke any credential that may have been exposed.

## Supported versions

Security fixes target the current public `main` branch. Experimental source builds and old snapshots may not receive backports.

## Scope boundary

This repository does not contain the hosted PixelCrabs platform, production credentials or private administration services. Reports about the public source should identify a file or reproducible behavior present in this repository.
